# 数学建模常见题型与经典算法整理

| 题型类别  | 问题本质      | 经典问题           | 常见数学模型         | 经典算法 / 方法                                     |
| ----- | --------- | -------------- | -------------- | --------------------------------------------- |
| 优化类   | 求最优方案     | 路径规划、资源分配、调度   | 线性规划、整数规划、组合优化 | 单纯形法、分支定界、动态规划、贪心、遗传算法（GA）、模拟退火（SA）、蚁群算法（ACO） |
| 路径规划类 | 最短/最低代价路径 | TSP、VRP、物流配送   | 图论、组合优化        | Dijkstra、Floyd、A*、最小生成树、GA、SA、ACO             |
| 调度类   | 多任务资源安排   | 车间调度、课程安排      | 整数规划、状态转移      | 动态规划、贪心、禁忌搜索、遗传算法                             |
| 预测类   | 根据历史预测未来  | 销量预测、人口预测、疫情预测 | 时间序列、回归分析      | 线性回归、ARIMA、灰色预测 GM(1,1)、LSTM                  |
| 评价决策类 | 多指标综合评价   | 企业评价、城市排名      | 多指标决策模型        | AHP、熵权法、TOPSIS、模糊综合评价                         |
| 分类聚类类 | 数据自动分组    | 用户分类、图像分类      | 聚类、机器学习        | K-Means、层次聚类、SVM、决策树                          |
| 数据分析类 | 从数据中提取规律  | 用户行为分析         | 统计分析、降维        | PCA、相关分析、回归分析、聚类分析                            |
| 机理分析类 | 建立现实规律模型  | 疫情传播、生态系统      | 微分方程、动力系统      | Logistic 模型、SIR 模型、数值解法                       |
| 概率统计类 | 不确定性分析    | 风险评估、抽样分析      | 概率模型、统计推断      | 假设检验、极大似然估计、贝叶斯方法、马尔可夫链                       |
| 图论网络类 | 网络结构分析    | 通信网络、社交网络      | 图论模型           | 最短路、最大流、PageRank、社区发现                         |
| 仿真类   | 模拟真实系统运行  | 交通系统、人群疏散      | 随机过程、系统仿真      | 蒙特卡洛、离散事件仿真、Agent-Based Model                 |
| 博弈对策类 | 多主体竞争合作   | 定价、市场竞争、军事博弈   | 博弈论            | 纳什均衡、极小极大、演化博弈                                |
| 控制优化类 | 动态系统控制    | 自动驾驶、无人机控制     | 最优控制           | PID、MPC、卡尔曼滤波                                 |
| 图像信号类 | 图像/声音处理   | 医学图像、目标识别      | 信号处理、深度学习      | FFT、小波分析、CNN                                  |
| 深度学习类 | 自动学习复杂规律  | NLP、视觉识别       | 神经网络           | CNN、RNN、Transformer                           |

# 常见算法缩写

| 缩写  | 全称                           | 中文     |
| --- | ---------------------------- | ------ |
| GA  | Genetic Algorithm            | 遗传算法   |
| SA  | Simulated Annealing          | 模拟退火   |
| ACO | Ant Colony Optimization      | 蚁群算法   |
| PSO | Particle Swarm Optimization  | 粒子群算法  |
| AHP | Analytic Hierarchy Process   | 层次分析法  |
| PCA | Principal Component Analysis | 主成分分析  |
| CNN | Convolutional Neural Network | 卷积神经网络 |
| RNN | Recurrent Neural Network     | 循环神经网络 |
| MPC | Model Predictive Control     | 模型预测控制 |
